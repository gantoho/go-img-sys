### 3. [P0] startTimes map 并发不安全

**文件**: `pkg/utils/response.go`

**问题**: `var startTimes = make(map[*gin.Context]time.Time)` 在多 goroutine 并发读写时存在 data race。

**修复**: 添加 `sync.RWMutex` 保护并发访问。

```go
var (
    startTimesMu sync.RWMutex
    startTimes   = make(map[*gin.Context]time.Time)
)
```

所有对 `startTimes` 的读写操作均加锁保护。

### 4. [P0] 图片缩放实现错误

**文件**: `pkg/imageutil/imageutil.go`

**问题**: 使用 `draw.Draw` 进行"缩放"，但其只做像素复制，不执行缩放算法。当原图与目标尺寸不同时，结果不正确。

**修复**: 使用标准库 `golang.org/x/image/draw` 的 `draw.CatmullRom` 高质量缩放算法，替换 `image/draw` 的 `draw.Draw`。

```go
import "golang.org/x/image/draw"

// Catmull-Rom 插值缩放
draw.CatmullRom.Scale(thumb, thumb.Bounds(), originalImg, originalImg.Bounds(), draw.Over, nil)
```

### 5. [P1] 图片旋转未实现

**文件**: `pkg/imageutil/imageutil.go`

**问题**: 90/270 度旋转仅创建了新 RGBA 图像但未填充像素数据，返回空画布。

**修复**: 实现完整的像素级旋转：遍历原图每个像素，旋转后写入目标位置。

```go
func rotatePixels(src image.Image, dst *image.RGBA, degrees int) {
    bounds := src.Bounds()
    for y := bounds.Min.Y; y < bounds.Max.Y; y++ {
        for x := bounds.Min.X; x < bounds.Max.X; x++ {
            switch degrees % 360 {
            case 90:
                dst.Set(bounds.Max.Y-1-y, x, src.At(x, y))
            case 270:
                dst.Set(y, bounds.Max.X-1-x, src.At(x, y))
            case 180:
                dst.Set(bounds.Max.X-1-x, bounds.Max.Y-1-y, src.At(x, y))
            }
        }
    }
}
```

### 7. [P2] Cache goroutine 泄露

**文件**: `pkg/cache/cache.go`

**问题**: `NewCache()` 启动的后台 `cleanup()` goroutine 无法被停止，缺少 `Close()` 方法。

**修复**: 添加 `stopCh` 通道和 `Close()` 方法，支持优雅退出。

```go
type Cache struct {
    mu     sync.RWMutex
    items  map[string]CacheEntry
    stopCh chan struct{}
}

func (c *Cache) Close() {
    close(c.stopCh)
}
```

### 14. [P3] logger.Fatal 使用 os.Exit

**问题**: `Fatal()` 直接 `os.Exit(1)`，不执行 deferred 函数。

    panic(msg)
}

### 17. [P3] 引入 swaggo/swag 自动生成 OpenAPI

**文件**: `cmd/image-sys/main.go`, `internal/handler/image.go`, `internal/router/router.go`, `scripts/Makefile`

**问题**: `openapi.yaml` 之前是手动维护的，容易遗漏、出错，且无法提供运行时 Swagger UI。

**方案选择**: 采用 Go 生态中最流行的 **swaggo/swag** + **swaggo/gin-swagger** 方案。

**实现**:
1. 在 `cmd/image-sys/main.go` 中添加全局 API 信息注解（标题、版本、描述、认证方式）
2. 为 `internal/handler/image.go` 中所有 23 个 handler 函数添加 Swagger 注解（@Summary、@Description、@Tags、@Param、@Success、@Router 等）
3. 在 `internal/router/router.go` 中注册 `/swagger/*` 路由，提供运行时 Swagger UI
4. 在 `scripts/Makefile` 中添加 `make openapi`、`make generate`、`make swag-install` 目标
5. 在 `cmd/image-sys/main.go` 中添加 `//go:generate` 注解

**触发方式（任选其一）**:
```bash
# go generate
go install github.com/swaggo/swag/cmd/swag@latest
go generate ./...

# Makefile
cd scripts && make openapi

# 直接运行
swag init -g cmd/image-sys/main.go -o docs --parseDependency --parseInternal
```

**生成产物**（`docs/` 目录）:
- `docs/swagger.yaml` — OpenAPI 3.0 YAML
- `docs/swagger.json` — OpenAPI 3.0 JSON
- `docs/docs.go` — 嵌入二进制的 Go 代码（供 gin-swagger 运行时加载）

**运行时 Swagger UI**: 启动服务后访问 `http://localhost:3128/swagger/index.html`

**注解分类标签**:
- `Images` — 图片 CRUD 操作
- `Files` — 文件访问
- `Admin` — API Key 管理
- `Utility` — 统计、导出、清理
- `Auth` — JWT 登录/刷新
- `System` — 健康检查

### 18. [P3] Swagger 运行时故障修复

**文件**: `internal/router/router.go`

**问题一 — gin-swagger 兼容性**：
- 使用 `ginSwagger.WrapHandler(swaggerFiles.Handler)` 时，`/swagger/doc.json` 返回 `500 Internal Server Error`，因为 `swaggo/gin-swagger` 与 `swaggo/swag` 库版本存在 API 不兼容

**问题二 — Gin 路由冲突**：
- 同时注册 `GET /swagger/doc.json`（静态路由）和 `GET /swagger/*any`（通配路由）时，Gin 路由树 panic：`catch-all wildcard '*any' in new path '/swagger/*any' conflicts with existing path segment 'doc.json'`

**问题三 — `docs` 包未导入**：
- 移除 `gin-swagger` 后，`docs/docs.go` 的 `init()` 未被执行，`swag.Register()` 未被调用，导致 `swag.ReadDoc()` 返回 `"no swag has yet been registered"`

**修复方案**：

1. 移除 `gin-swagger` 依赖，改用 `swag.ReadDoc()` 直接渲染
2. 将 `/swagger/doc.json` 和 `/swagger/*any` 合并到同一个通配路由中，在 handler 内根据 path 分发
3. 添加 `_ "github.com/gantoho/go-img-sys/docs"` 导入，触发 `init()` 注册 swag 定义
4. 手动读取 `swaggerFiles.HTTP` embed FS 中的静态文件，适配正确的 Content-Type

```go
router.GET("/swagger/*any", func(c *gin.Context) {
    path := c.Param("any")
    
    if path == "/doc.json" {
        doc, err := swag.ReadDoc()
        // ... 渲染模板 ...
    }
    
    // 读取 swagger-ui 静态文件
    f, _ := swaggerFiles.HTTP.Open("swagger-ui" + filePath)
    content, _ := io.ReadAll(f)
    c.Data(200, contentType, content)
})
```
